## 文档约定

每个主分类的概念说明是总文档；各案例子目录包含示例图和独立分析报告。报告覆盖分类依据、数据结构、统计图形及应用、视觉编码、信息框架、叙事框架、适用边界及更新记录。非统计型作品明确说明其图解形式，不强行编造统计图。

新增案例先审核再入库。每次维护同步修改分类总文档与本索引；本库没有自动更新服务。详见[维护规范](CONTRIBUTING.md)与[素材清单](素材清单.md)。

首批来源：[SCMP Print arcade](https://multimedia.scmp.com/culture/article/SCMP-printed-graphics-memory/)。保存作者、档案年月、原图和预览图链接；档案日期仅记录网页目录给出的精度，不臆造具体日期。图片版权归原作者及发布方；这里没有授予原图的再利用许可，也未为整库添加覆盖第三方素材的开源许可证。图形分析不代表原作者观点，不将历史作品内容冒充当前事实。
