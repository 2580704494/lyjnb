# 常用信息图形案例库

按用户指定建立[词云图](%E8%AF%8D%E4%BA%91%E5%9B%BE/02%E5%88%86%E6%9E%90%E6%8A%A5%E5%91%8A.md)、[HOW-TO](HOW-TO/02%E5%88%86%E6%9E%90%E6%8A%A5%E5%91%8A.md)、[文字型信息图](%E6%96%87%E5%AD%97%E5%9E%8B%E4%BF%A1%E6%81%AF%E5%9B%BE/02%E5%88%86%E6%9E%90%E6%8A%A5%E5%91%8A.md)三个类型。每类包含示例图目录和六份分析文档。

当前均为待补充模板，已收录案例数为0。五大类型描述信息的组织原则，本目录描述常见表达或用途，两套分类可以交叉，但交叉收录必须写明依据、引用同一来源并避免重复计数。后续其他类型按用户给出的名称逐一新增。
